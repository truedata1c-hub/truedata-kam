# PharmaCheck · Переговоры — руководство администратора клиента

Всё настраивается в разделе **«Настройки переговоров»** (виден ролям с полномочием «Администрирование»). Изменения записываются в «Журнал изменений».

Рекомендуемый порядок первой настройки: роли → сотрудники и оргструктура → сети и юрлица → бренды → типы кампаний → маршруты согласования → прошлые периоды → пороги и почта.

## 1. Роли

Роль = набор полномочий + область видимости. Сотруднику можно дать несколько ролей.

| Полномочие | Что даёт |
| --- | --- |
| Вести кампании | Создавать и вести свои кампании по закреплённым сетям |
| Вести кампании подчинённых | То же за сотрудников своей ветки оргструктуры |
| Согласовывать | Быть исполнителем шага маршрута |
| Аналитика | Экран «Аналитика» в своей области видимости |
| Администрирование | Этот раздел |

| Область видимости | Что видно |
| --- | --- |
| Свои сети | Кампании по сетям, за которыми сотрудник закреплён |
| Сети подчинённых | Плюс всё, что видят подчинённые любой глубины |
| Все сети | Все кампании клиента |
| Свои бренды | Все кампании, но суммы детально — только по брендам сотрудника, остальное — итогом |

Согласующий всегда видит кампанию, по которой он исполнитель шага (или замещает исполнителя), даже вне своей области. Последнюю роль с администрированием удалить нельзя. Роль, стоящую в шаге маршрута, нельзя лишить права согласования — сначала уберите её из шагов.

## 2. Сотрудники и оргструктура

- **Пригласить** — сотрудник получает временный пароль и меняет его при первом входе. При сквозном входе из платформы учётная запись создаётся автоматически, роли назначает администратор.
- **Руководитель** — цепочка любой глубины, действует с даты. От неё зависят маршруты («руководитель автора») и видимость «сети подчинённых».
- **Закрепление за сетями** действует по датам. В один день сеть может быть закреплена только за одним КАМом компании. Чтобы передать сеть, откройте «Пользователи» → карточку прежнего КАМа → «Сети» и нажмите «Открепить». Затем в карточке нового КАМа выберите сеть, дату начала и нажмите «Закрепить». Если даты пересекаются, предупреждение покажет имя сотрудника, за которым закреплена сеть.
- **Бренды сотрудника** — для области «Свои бренды».
- **Замещения** (отдельная страница) — кто кого замещает на даты. Заместитель получает шаги отсутствующего и решает их «за» него. Сотрудник может назначить заместителя себе сам в разделе «Мои решения».

## 3. Сети, юрлица, бренды

- **Сети** — название, регионы, группа сетей (для правил маршрутов и фильтров), юрлица с ИНН (проверяется контрольная сумма). По ИНН PharmaCheck отслеживает исполнение, поэтому в кампании выбираются юрлица сети — по умолчанию все действующие.
- **Контакты сети** ведут КАМ в карточке кампании (вкладка «Работа с сетью»), они общие для всех кампаний сети.
- **Бренды** — справочник клиента; по брендам строится разбивка предложений и аналитика.

## 4. Типы кампаний

Тип задаёт деление периода в разбивке (квартал, месяц, четыре месяца, весь срок) и сколько дней до начала периода ставится контрольная дата по умолчанию. Тип, по которому есть кампании, удалить нельзя.

## 5. Маршруты согласования

**Шаблон** — шаги по порядку. У шага:

- **исполнитель**: руководитель автора (непосредственный или N-го уровня), бизнес-роль (можно оставить только тех, кто видит сеть кампании) или конкретный сотрудник;
- **условия включения** (все должны выполняться, иначе шаг пропускается): инвестиции не меньше суммы, рост к факту прошлого периода не меньше %, ROI ниже прошлого, тип, сеть, группа сетей, бренд в разбивке. Без данных прошлого периода условия по росту и ROI считаются выполненными;
- **срок решения** в рабочих днях; в день срока — напоминание, при просрочке — уведомление исполнителю и его руководителю.

**Допуски** шаблона: если после «Согласовано внутри» КАМ добавит версию, где инвестиции выросли не больше допуска, а оборот снизился не больше допуска, согласование сохраняется; иначе кампания возвращается в переговоры.

**Правила выбора** проверяются сверху вниз (тип кампании и/или группа сетей); если ни одно не подошло — шаблон по умолчанию. Шаблон по умолчанию обязателен.

**Предпросмотр** в конструкторе показывает на любой кампании, какие шаги получатся и кто их исполнит. При отправке маршрут фиксируется: правка шаблона не меняет уже идущие согласования.

Защиты: автор отправки и ответственный КАМ не могут согласовывать свою кампанию — их шаг уходит руководителю следующего уровня; отклонить можно только с комментарием; отклонённую версию нельзя отправить повторно.

## 6. Прошлые периоды

План и факт инвестиций и оборота по сети × бренду × кварталу. Скачайте шаблон Excel за год, заполните, загрузите: загрузка заменяет данные года целиком; при любой ошибке ничего не меняется, показывается список строк с ошибками. С этими данными сравниваются версии предложений и аналитика.

## 7. Настройки

- **Пороги подсветок**: рост инвестиций бренда к факту (по умолчанию 15 %), выполнение плана прошлого периода (90 %), ROI ниже прошлого. Подсветки видны КАМ и согласующим и не запрещают отправку.
- **Почтовый канал**: сервер SMTP, порт, логин, пароль, адрес отправителя. До подключения письма копятся и уходят после него. «Отправить проверочное письмо себе» проверяет канал. Журнал писем показывает статус каждого письма; недоставленное можно повторить. Какие события приходят письмом, каждый сотрудник выбирает сам в центре уведомлений.
- **Резервные копии**: когда сделана последняя копия и её размер.

## 8. Журнал изменений

Все изменения настроек и кампаний: кто, когда, что было и что стало. Журнал нельзя изменить или удалить.
